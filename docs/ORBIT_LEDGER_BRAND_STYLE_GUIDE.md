# Orbit Ledger Brand And UI Style Guide (retired)

**This guide is superseded by [`ORBIT_LEDGER_DESIGN_SYSTEM.md`](./ORBIT_LEDGER_DESIGN_SYSTEM.md).**

It described the previous visual direction — "calm, restrained, quiet
confidence," soft off-white surfaces, a blue primary, and an instruction to
avoid gradients and decoration. That direction was deliberately retired: it
produced a product that read as generic, which was the motivation for the
redesign.

Do not follow this document. Values and rules now live in
`apps/web/app/tokens.css` and the design system doc above.

The original text remains in git history if the earlier rationale is needed.
